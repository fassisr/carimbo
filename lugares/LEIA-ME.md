# Lugares extras

Crie aqui um arquivo `.json` por cidade (por exemplo `sp-sao-paulo.json`) com a lista de lugares no formato:

```json
[
  { "n": "Nome do lugar", "cat": "cafe", "end": "Rua Exemplo, 123, Bairro", "cidade": "São Paulo", "uf": "SP", "d": "Por que vale a visita." }
]
```

Categorias: `cafe`, `bar`, `doce`, `verde`, `cultura`, `comida`. Ao salvar, o GitHub acha a posição de cada lugar e atualiza o mapa do app sozinho.
