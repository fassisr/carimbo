# Carimbo

Jogo de colecionar lugares. Abra o mapa, veja cafés, bares, padarias, parques e espaços culturais reais perto de você, chegue a 60 m e faça check-in para ganhar carimbos, insígnias, XP e um cupom de primeira visita.

Protótipo em um único `index.html`:

- Localização pelo GPS do navegador, com modo demo (toque no mapa para andar).
- Lugares do OpenStreetMap via Overpass API, mapa da CARTO com Leaflet.
- Notas e ofertas são de exemplo nesta versão.
- Progresso salvo no próprio aparelho (localStorage).

Publicado com GitHub Pages a partir da branch `main`.
